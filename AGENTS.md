# Project rules

- Write all project content in English, including code comments, documentation, prompts, configuration descriptions, and commit messages.
- Do not use emoji.
- Do not use em dashes. Use commas, parentheses, colons, or separate sentences instead.
- Use OpenSandbox as the execution environment for agent workloads.
- Keep infrastructure controls outside the harness that agents can modify.
- Keep credentials, local datasets, execution traces, screenshots, and generated artifacts out of Git unless explicitly selected for publication.
- State whether a component is proposed, implemented, or verified. Do not describe a scaffold as a working integration.
